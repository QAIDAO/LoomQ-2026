# 门分解速查表（照抄即可）

> **用途**：当某个后端的导入器报"不支持门 X"时，用下面的恒等式把 X 改写成更基础的门，
> 无需推导。**全部恒等式已经官方参考模拟器数值验证**（末态一致，至多相差一个全局相位——
> 全局相位不影响任何测量分布）。
>
> 白名单 12 门中，`h / x / cx` 各平台必有；其余 9 个门如遇不支持，按本表降级。

---

## 1. 相位门家族都是 u1 的特例

| 原门 | 等价写法 |
|---|---|
| `z q[k];` | `u1(pi) q[k];` |
| `s q[k];` | `u1(pi/2) q[k];` |
| `sdg q[k];` | `u1(-pi/2) q[k];` |
| `t q[k];` | `u1(pi/4) q[k];` |
| `tdg q[k];` | `u1(-pi/4) q[k];` |

## 2. rz 与 u1 的关系（注意适用范围）

`rz(θ)` 与 `u1(θ)` 只差全局相位 e^(−iθ/2)：

- **直接作为电路中的单比特门时可互换**（测量分布完全相同）；
- **作为受控门分解的组成部分时不可互换**（相对相位会错）。本表第 4 条的 cu1 分解必须用 `u1`；若后端只有 `rz`，先确认它的 `u1`/`p`/`phase` 等价门名。

## 3. swap = 3 个 cx

```text
swap q[a], q[b];
// 等价于：
cx q[a], q[b];
cx q[b], q[a];
cx q[a], q[b];
```

## 4. cu1（受控相位门，qelib1 官方定义）

```text
cu1(θ) q[a], q[b];
// 等价于：
u1(θ/2) q[a];
cx q[a], q[b];
u1(-θ/2) q[b];
cx q[a], q[b];
u1(θ/2) q[b];
```

## 5. ccx（Toffoli，qelib1 标准分解：2 比特门 6 个 + 单比特门 9 个）

```text
ccx q[a], q[b], q[c];
// 等价于：
h q[c];
cx q[b], q[c];
tdg q[c];
cx q[a], q[c];
t q[c];
cx q[b], q[c];
tdg q[c];
cx q[a], q[c];
t q[b];
t q[c];
h q[c];
cx q[a], q[b];
t q[a];
tdg q[b];
cx q[a], q[b];
```

## 6. ry 兜底

`ry(θ)` 是最基础的旋转门之一，主流平台均原生支持。若确实缺失，按以下电路时序改写（经数值验证）：

```text
ry(θ) q[k];
// 等价于（按行序依次施加）：
sdg q[k];
h q[k];
rz(θ) q[k];
h q[k];
s q[k];
```

或直接查该平台的 `u3`/`u` 通用门：`ry(θ) = u3(θ, 0, 0)`。

---

**自验方法**：把"原门版"和"分解版"两个电路分别喂给你的 `run(qasm, target, shots)`，
在任意无噪声模拟器上对比 counts 分布——分布一致即改写正确。这同时是对你中间层的一次免费回归测试。
